# vacancy-ai-parser

MVP-агент: ищет вакансии в открытых данных Роструда и отправляет подходящие
в Telegram через LLM-ассистента.

## Как работает

1. Пользователь задаёт запрос, например: «Найди вакансии для Python разработчика».
2. LLM-агент вызывает инструмент `get_vacancies` — поиск по API
   `https://opendata.trudvsem.ru/api/v1/vacancies` (фильтр по ключевому слову и минимальной зарплате).
3. Агент отбирает действительно подходящие вакансии и отправляет каждую
   через `notify_user` в Telegram.
4. Уже отправленные вакансии сохраняются в `seen_vacancies.json` — повторно
   они не отправляются.

## Требования

- Python 3.12+
- [uv](https://docs.astral.sh/uv/) (для окружения и зависимостей)
- Telegram-бот (токен) и его chat_id получателя
- OPENCODE_API_KEY — ключ для LLM API

## Установка

```bash
uv sync
cp .env.example .env
```

## Настройка (.env)

| Переменная         | Обязательная | Описание                                   |
| ------------------ | ------------ | ------------------------------------------ |
| `OPENCODE_API_KEY` | да           | Ключ API для LLM                           |
| `TG_TOKEN`         | да           | Токен Telegram-бота                        |
| `TG_CHAT_ID`       | да           | ID чата/пользователя для отправки вакансий |

## Запуск

```bash
uv run python main.py
```

Запрос по умолчанию задан в `main.py` (`Найди вакансии на Python, грейд Middle`).

## Структура проекта

```
main.py              # точка входа: загрузка .env и запуск агента
src/agent.py         # LLM-цикл с вызовом инструментов
src/tools.py         # get_vacancies (Trudvsem) и notify_user (Telegram)
seen_vacancies.json  # служебный файл дедупликации (создаётся автоматически)
.env.example         # шаблон переменных окружения
```

## Ограничения (MVP)

- Модель и base_url LLM захардкожены в `src/agent.py`
  (`deepseek-v4-flash-free`, `https://opencode.ai/zen/v1`)
- Цикл вызова инструментов не имеет лимита итераций (`max_rounds`)
- Поиск идёт только по открытым данным trudvsem.ru
