# Vacancy AI Parser (MVP) 🤖🔎

AI-агент для автоматизации поиска работы. Ищет свежие вакансии в API Роструда («Работа России»), фильтрует их через LLM под критерии пользователя и отправляет релевантные в Telegram.

## 🏛 Архитектура (Tool Use)
[API Роструда] ──> (get_vacancies) ──> [LLM Агент (DeepSeek)] ──> (notify_user) ──> [Telegram Bot]│(seen_vacancies.json)

1. **Ядро (`main.py`):** Управляющий цикл агента. Передает контекст в LLM, защищен от бесконечных циклов и падений JSON.
2. **Инструменты (`src/tools.py`):** `get_vacancies` (парсер API с ретраями) и `notify_user` (дедупликация и отправка в Telegram).
3. **БД (`seen_vacancies.json`):** Локальный кэш ID вакансий для защиты от спама.

## 🚀 Быстрый старт

1. **Установите зависимости:**
   ```bash
   pip install openai requests
   ```
2. **Настройте окружение (Env):**
   - `OPENCODE_API_KEY` — API-ключ вашей LLM
   - `TG_TOKEN` — токен бота от `@BotFather`
   - `TG_CHAT_ID` — ID вашего чата в Telegram

3. **Запуск:**
   ```bash
   python main.py
   ```

## ⚠️ Ограничения MVP
- **Схема TOOLS:** Передача объекта `vacancy` целиком в LLM может вызвать галлюцинации полей (лучше заменить на плоские аргументы: `id`, `url`, `name`).
- **Синхронный I/O:** Запись файла базы при каждом вызове инструмента создает риск race condition при параллельной работе.
